Engram

Privacy policy

Last updated 18 November 2026.

Where data lives

Engram is a desktop app that runs on the user’s own Mac. Everything it stores (the study plan, timetable, notes and settings) is kept in a database on that Mac. The developer runs no server and receives no data. There are no analytics, ads or tracking.

Google user data

When the user connects Google Calendar, Engram asks for one permission, https://www.googleapis.com/auth/calendar.app.created, which lets it create a calendar and manage that calendar only. It uses it to:

  • create one calendar named for Engram in the user’s Google account;
  • add, update and remove events in that calendar: the user’s own planned study blocks, lectures and deadlines.

Engram cannot see the user’s other calendars or events, and it does not read Google data for any other purpose. Google data is not sold, shared with anyone, used for advertising or used to train AI models. It is only sent between the user’s Mac and Google.

The sign-in token Google issues is stored on the user’s Mac, encrypted with the macOS Keychain. Signing out in Engram deletes it. Access can also be removed at any time at myaccount.google.com/permissions; deleting the Engram calendar in Google Calendar removes everything Engram wrote there.

Other services

Engram can also read a timetable feed, a local Zotero library and the Tot app on the same Mac, and can send text the user chooses to Anthropic’s Claude using the user’s own Claude account. None of this involves Google user data.
